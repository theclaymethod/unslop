# /unslop ste100

Rewrite teaching or technical copy with ASD-STE100-style Simplified Technical
English. Preserve facts, uncertainty, conditions, and approved terms of art.
Do not claim formal ASD-STE100 compliance unless the copy has been checked
against the complete controlled vocabulary and grammar.

Input arrives as an argument, a file path, or stdin. The user can supply
approved terms with `--terms`. Read
`presets/ste100-engineering.md` before writing. Treat it as a pre-built voice
card: a streamlined engineering persona, not a sample of the user's personal
voice.

## 1. Preserve meaning

1. Extract facts and constraints:
   ```bash
   python3 scripts/extract_constraints.py <<< "$INPUT"
   ```
2. Record terms that must remain:
   - terms supplied through `--terms`;
   - proper nouns, code identifiers, API names, units, and regulated terms;
   - domain terms whose replacement would reduce precision.
3. Record uncertainty, negation, scope, and every `if`, `when`, `until`, or
   `unless` condition.

Ask one focused question only when the approved vocabulary is ambiguous and a
wrong choice would change meaning. Otherwise, preserve the smallest necessary
set of precise terms.

## 2. Rewrite

- Use one approved word for one meaning.
- Use short, declarative sentences without repetitive staccato.
- Put the actor before the action when the actor is known.
- Keep one main action in each sentence.
- State conditions explicitly.
- Replace an ambiguous pronoun with its referent.
- Break noun stacks into actors, actions, evidence, and results.
- Define an abbreviation at first use.
- Put instructions in the order the reader performs them.
- Preserve necessary clinical, legal, scientific, safety, and technical
  precision.

Simplify the sentence after the causal model is correct. Do not turn a difficult
relationship into a short unexplained label.

## 3. Validate

Run the full validation battery in `SKILL.md`. Use strict preservation for
legal, medical, security, scientific, and safety text:

```bash
python3 scripts/validate_preservation.py --strict original.txt transformed.txt
python3 scripts/banned_phrase_scan.py <<< "$OUTPUT"
python3 scripts/structure_scan.py --genre docs <<< "$OUTPUT"
python3 scripts/silhouette_scan.py --genre docs <<< "$OUTPUT"
python3 scripts/readability_metrics.py <<< "$OUTPUT"
python3 scripts/diff_check.py original.txt transformed.txt
```

Re-read the output for stable terminology, explicit conditions, and preserved
certainty. The existing anti-slop and fact-preservation gates still block the
return.

Return the transformed text only unless the user asks for a report. In a
report, list the preserved terms, conditions, and any sentence that remains
complex because precision requires it.
